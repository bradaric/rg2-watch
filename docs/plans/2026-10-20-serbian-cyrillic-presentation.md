# Serbian Cyrillic Results Graphic Implementation Plan

> **For agentic workers:** REQUIRED: Use subagent-driven-development (if subagents available) or executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the results graphic, both embedded and in presentation mode, read in Serbian Cyrillic without changing tally calculations, source names, or CSV/CLI outputs.

**Architecture:** Localize display strings in `src/rg2watch/static/index.html`'s `#hero` markup and hero-rendering functions. Add a narrow display-only translator for the finite set of tally configuration warnings generated by `src/rg2watch/tally.py`. Add metadata-only fields to the tally payload identifying generated fallback list names and unknown municipalities so the graphic can localize them without guessing from their text; leave existing payload fields and exports untouched. Keep internal option values, numeric format, model IDs, genuine data/configured names, election titles, rule codes, and `RG-2`/`RG-7` identifiers unchanged. Do not rewrite `resultCols`, `tallyCsv`, `listsOf`, the results tables, or the forms/status UI.

**Tech Stack:** Inline HTML/JavaScript, Python pytest, existing Node-based JS execution tests in `tests/test_tally.py`.

Unknown future diagnostics must stay visible verbatim rather than disappearing or receiving a misleading generic translation; tests should flag any new source warning for future localization.

The graphic currently cannot tell a generated `List 1` from an actual configured `List 1`. The user approved additive payload metadata for that distinction after review, while retaining original name fields and exports.

## Acceptance criteria

1. All authored, user-visible prose in the results graphic is Serbian Cyrillic in embedded and presentation mode, including the recently added vote-reconciliation and cohort explanations; badges and controls remain usable.
2. No change to calculations, filters, chosen view, polling, numeric values, existing name fields, or CSV/CLI text. The only tally payload change is additive metadata distinguishing generated placeholders; program identifiers and official RG identifiers remain intact.
3. Every known tally configuration warning displayed within the graphic has a Serbian Cyrillic rendering; unknown future warnings remain visible rather than silently discarded.
4. Tests demonstrate localized states and preserve safety (`textContent`/DOM construction rather than inserting untrusted HTML); full test suite is run and results reported.
