# Results Hero Serbian Wording Implementation Plan

> **For agentic workers:** REQUIRED: Use subagent-driven-development (if subagents available) or executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the public Serbian results hero concise and consistent across corrected, original RG-2, and difference views without changing tally calculations or the operator-facing results table.

**Architecture:** Keep `build_tally`, JSON field meanings, view selection, and operator-facing English table/CSV unchanged. Update only the public hero's Serbian HTML options, JavaScript labels/rendering, and CSS for multiline tile details. Preserve `textContent`/DOM-safe rendering and use newline-delimited text plus `white-space: pre-line` rather than HTML interpolation.

**Tech Stack:** Single-file HTML/CSS/vanilla JavaScript (`src/rg2watch/static/index.html`), Python pytest and Node-powered browser-logic test (`tests/test_tally.py`).

---

## File map and boundaries

- Modify `src/rg2watch/static/index.html`: public hero selectors (`hmode`, `hview`), hero title, status text, tile captions, detail formatting, and hero-only CSS. Do **not** change the operator's `tmode`/`tview` controls or English `NV_LABEL`, tally/CSV headings, API schema, or status banner at the top of the page.
- Modify `tests/test_tally.py`: static hero assertions and the existing Node test `test_results_javascript_uses_selected_view_and_exports_explicit_unavailable_lists`, exercising all three numeric views, clean/all selection, footer, empty states, and multiline details. Keep the operator/CSV assertions intact.

## Scope guardrails

- No Python tally logic, metadata or data-format changes; no new dependencies.
- Do not translate or redesign the operator-facing English detail section, CSV, or global page navigation/status.
- The title's suffix is based on the **chosen numeric view** even if no RG-7 was applied in a selected municipality. `filed` always has no suffix; the selector communicates that it shows original RG-2 numbers.
- The footer only claims AI processing, not official verification; `без уочених проблема` must not be treated as an official RIK assessment.
